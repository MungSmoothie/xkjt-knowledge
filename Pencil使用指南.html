Pencil VSCode 设计插件使用指南

版本 v1.0 · 2026-03-27 · 适用于：设计师 & 开发者

Pencil 是什么

一句话定位

直接在 VSCode 里做 UI 设计并导出代码的 AI 设计工具，支持 React / Tailwind CSS / Next.js 代码导出。

定位设计+代码二合一工具
安装VSCode 扩展商店 / Cursor 插件
文件格式.pen（JSON格式，可用 Git 管理）
导出React / Tailwind CSS / Next.js
AI 集成MCP 协议，接入 Claude Code / Cursor

安装方法

1

打开 VSCode 扩展面板

按 Ctrl + Shift + X 或点击左侧扩展图标

2

搜索 "Pencil"

在扩展商店搜索框输入"Pencil"，找到官方插件（发布者为 Pencil Dev）

3

安装并重启

点击安装，重启 VSCode，侧边栏会出现铅笔图标 ✏️

Mac 用户也可以下载桌面版：pencil.dev/downloads

Stitch + Pencil 工作流

Stitch 和 Pencil 是两个互补的工具，组合使用效率翻倍：

Stitch 生成初稿
→
Pencil 精细调整
→
AI 修改细节
→
导出代码
步骤工具操作
1Stitch用 AI 对话生成初始 UI 界面
2Pencil导入 Stitch 截图，在 VSCode 里打开
3Pencil + AI用自然语言提示词修改细节（如"改成暗红色主题"）
4Pencil点 Export，选择 React/Tailwind，复制代码

Stitch 稿子导入 Pencil 步骤

1

在 Stitch 中导出设计稿

Stitch 支持导出截图或生成分享链接，用于后续编辑

2

VSCode 打开 Pencil

点击侧边栏铅笔图标 ✏️，新建或打开一个 .pen 文件

3

拖入 Stitch 截图

直接把 Stitch 的截图拖入 Pencil 画布，Pencil 会自动识别组件边界

4

用 AI 提示词修改

在输入框输入自然语言，如"把这个按钮改成 #8b2635 暗红色，圆角加大"

5

导出代码

右上角点 Export → 选择 React / Tailwind / Next.js → 复制粘贴到项目

Pencil 免费版 AI 生成次数有限，高级功能需要登录账号解锁

常用 AI 提示词示例

# 修改按钮颜色 把这个按钮的背景色改成 #8b2635，文字改成白色 # 修改字体 课程标题的字体加大到 20px，字重加粗 # 添加组件 在课程卡片右下角添加一个"会员免费"标签，背景用金色 # 修改布局 把章节目录从左侧移到右侧 # 添加交互 给播放按钮添加鼠标悬浮效果
提示词越具体，AI 生成效果越好。建议一次只改一个点，不要一次性提太多要求。

常用快捷键

新建 .pen 文件Ctrl + Alt + N
打开 Pencil 侧边栏Ctrl + Shift + P → "Pencil"
AI 生成在画布顶部输入框输入提示词
导出代码画布右上角 Export 按钮
撤销Ctrl + Z

Pencil + Claude Code 联动

Pencil 支持 MCP 协议，可以直接让 Claude Code 操作设计稿：

1

在 Pencil 中获取连接码

打开 Pencil App → 点击 Connect → 复制显示的邮箱地址

2

在 Claude Code 中连接

运行 /mcp 命令，确认 pencil 已连接

3

用自然语言改设计

在 Claude Code 里输入"帮我把这个登录页的按钮改成暗红色主题"

# Claude Code 中可用的 Pencil 命令 /pencil generate "创建一个课程详情页面，包含视频播放器" /pencil modify "把导航栏背景改成深色" /pencil export --format react

🎯 用 Pencil 做"小动物科研培训平台"设计

结合俺们知识库里的 UI 设计规范，可以这样用 Pencil：

1

导入俺的 UI 设计规范

把咱平台的色彩变量（#8b2635 暗红 / #faf8f3 米白）作为提示词基础

2

AI 生成初稿

输入："创建一个课程列表页面，使用暗红色 #8b2635 为主色调，米白色 #faf8f3 为背景"

3

导出代码

导出为 React + Tailwind CSS，直接应用到项目

# 小动物平台专用的 AI 提示词示例 "设计一个课程详情页，主色 #8b2635，背景 #faf8f3， 包含课程封面、讲师介绍、章节列表、购买按钮。 参考俺们知识库里的 UI 规范文档。"
