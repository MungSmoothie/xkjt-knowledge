👥 团队协作

GitHub协作流程与代码规范 · 2026年3月

一、最低团队配置（4人）

角色人数职责
前端开发1人Next.js/Vue3，页面交互，用户体验
后端开发1人NestJS/Go，API，数据架构
AI/视频工程师1人AI功能集成，视频处理，直播链路
产品/UI1人PRD，交互设计，运营后台

二、GitHub 协作流程

🌿 分支策略

main（生产） + dev（开发） + feature/*（功能分支）

保护分支：main 和 dev 不能直接 push，需要 PR。

✅ PR 要求

2人 Review 通过后才能合入 dev。必须通过 CI（自动化测试+lint）。

📐 代码规范

ESLint + Prettier，提交前必须 lint。TypeScript 严格模式。

🔄 CI/CD

GitHub Actions 自动测试 + 自动部署到 Vercel（前端）和腾讯云（后端）。

三、开发阶段规划

阶段功能周期
Phase 1登录注册 + 设备码兑换2周
Phase 2视频点播（VOD）+ 课程列表3周
Phase 3搜索、收藏、学习记录2周
Phase 4直播功能（CSS）3周
Phase 5AI 助手（预留接口）2周（暂缓）
Phase 6支付、会员、个人中心2周
Phase 7SEO、域名备案、正式上线2周
合计4人并行 10-14周

四、沟通协作

💬 日常沟通

飞书/钉钉群，每日站会（5分钟），周报同步进展。
