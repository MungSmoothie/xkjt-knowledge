🏗️ 系统架构

技术架构设计与模块关系 · 2026年3月

一、整体架构

Next.js 14 (前端) → NestJS/Go (后端 API) → MySQL + Redis + 腾讯云服务

二、技术栈

🖥️ 前端

Next.js 14 · React 18 · TypeScript · TailwindCSS · Zustand（状态管理）

⚙️ 后端

NestJS（API优先）或 Go（Gin/Echo）· MySQL 8.0 · Redis 7 · JWT 认证

☁️ 基础设施

腾讯云 VOD · COS · CSS · CVM · MySQL · Redis · Cloudflare

🎬 视频

Video.js + flv.js · HLS+FLV 双协议 · 跑马灯水印

三、核心模块

模块功能技术选型
用户认证注册/登录/设备码兑换JWT + 手机号
权限管理US/IC/MX 设备码权限RBAC + 设备码表
课程管理课程列表/详情/目录MySQL + COS
视频点播上传/转码/播放腾讯云 VOD
直播服务推流/拉流/弹幕腾讯云 CSS
支付系统会员购买/单课购买微信支付/支付宝
讲师分账收入结算/提现微信分账API
数据分析学习记录/转化漏斗MySQL + Redis

四、安全设计

🔒 传输安全

HTTPS 全站加密 · HSTS 强制跳转 · TLS 1.3

🎫 接口安全

JWT 签名验证 · 接口限流（Redis）· CSRF Token

📹 视频安全

URL 动态签名（防下载）· 跑马灯水印（溯源）· Referer 防盗链
