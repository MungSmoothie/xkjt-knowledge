📹 直播功能

直播技术链路、功能清单与合规要求 · 2026年3月

一、技术链路

讲师端：OBS/直播姬 → 腾讯云 CSS → CDN 分发 → 用户端（3-5秒延迟）
播放器：flv.js（HLS + FLV 双协议），兼容主流浏览器

二、功能清单

功能说明优先级
直播预约用户提前预约，开播前30分钟推送通知必须
实时弹幕学员发送弹幕，讲师端可过滤敏感词必须
连麦互动学员申请连麦，讲师同意后接入备选
课程回放自动录制，剪辑后上架（需人工审核）必须
白板/屏幕共享讲师演示操作步骤备选
打赏/积分学员打赏讲师的互动机制暂缓

三、合规要求（最高风险）

⚠️ 直播前

讲师签合规承诺书，禁止展示患者隐私。课程内容提前报备。

⏱️ 直播中

开启 30 秒延迟播放，人工实时巡检弹幕。AI 内容审核过滤敏感信息。

📹 直播后

录像经人工审核后方可对外展示。未审核版本不得公开。

四、成本估算

项目月成本备注
CSS 直播转码¥100-200月均500观众
CDN 流量¥200-500直播带宽峰值
录制存储¥100-200月均新增20小时
合计约¥400-900/月

五、播放器选型

flv.js + Video.js（推荐）

支持 HLS 和 FLV 双协议。HLS 延迟3-8秒，FLV 延迟1-3秒。移动端兼容性最好。

DPlayer

开源免费，支持弹幕。适合录播场景。
