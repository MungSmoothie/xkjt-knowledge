二、核心业务流程

2.1 用户注册 → 设备码兑换 → 课程学习

用户端核心流程
用户输入手机号
→获取验证码（60秒倒计时）
→填入验证码，完成注册
→进入课程首页（无权限状态）
→输入设备码（12位字母数字）
→系统校验设备码有效性、类型、有效期
→绑定成功，自动解锁对应课程权限
→开始视频学习（播放/进度记录）

2.2 会员购买 → 课程学习

付费流程
选择课程，点击购买
→选择支付方式（微信/支付宝）
→唤起支付 SDK
→支付成功 → 自动开通课程权限
→开始视频学习

2.3 设备码手动添加流程（运营端）

运营端设备码管理
运营人员 → 设备码管理
→方式一：手动单个添加（填设备码+类型+有效期+关联课程）
→方式二：Excel 批量导入（模板下载→填写→上传）
→系统校验格式、唯一性、类型
→入库，状态=未发放
→导出给经销商/客户

三、功能详细设计

3.1 用户认证

3.1.1 发送验证码

功能POST /api/v1/auth/send-code
参数phone（必填，11位手机号）string
频率限制同一手机号60秒内只能获取一次
返回{code: 0, message: "发送成功"}

3.1.2 登录

功能POST /api/v1/auth/login
参数phone, code（6位数字验证码）string
返回{token, refresh_token, user: {id, phone, nickname}}
TokenJWT，有效期7天

3.1.3 设备码兑换

功能POST /api/v1/device/redeem
参数code（12位设备码，如 XK-US-20260301-0001）string
前置需已登录
业务规则 ① 校验码存在且状态=未发放/未过期
② 同一设备码不能重复兑换（同一用户也不行）
③ 兑换后状态变为「已兑换」，记录 user_id、redeemed_at
返回{success: true, permissions: ["course_1", "course_3"]}
⚠️ 设备码兑换规则
  • US类型 → 解锁所有超声类课程ID
  • IC类型 → 解锁所有设备操作类课程ID
  • MX类型 → 解锁全部课程
  • 同一用户可兑换多类型码，权限取并集
  • 同一设备码不可重复兑换，重复兑换返回「已兑换」错误

3.2 课程学习

3.2.1 课程首页

  • Banner：3-5张，支持点击跳转
  • 分类筛选：顶级分类（超声/CT/外科/设备操作）+ 二级分类
  • 排序：最新/最热/评分
  • 搜索：课程名称/讲师名 模糊搜索
  • 课程卡片：封面图+标题+讲师+价格/会员免费+学习人数
  • 权限标识：已购买/设备码可看/未解锁（灰显）

3.2.2 课程详情页

  • 信息区：封面图+标题+讲师介绍+适合人群+学习目标
  • 目录区：章节列表，显示已解锁/未解锁
  • 价格区：单课价（¥99-299）或会员专享
  • 操作区：立即购买 / 已购买开始学习

3.2.3 视频播放器

播放器核心功能：
  • 基于 Video.js + flv.js，支持 HLS（直播延迟低）和 FLV 两种格式自动切换
  • 跑马灯水印：每30秒刷新一次，显示用户手机号后4位 + 时间戳
  • 防盗链：播放 URL 动态签名，5分钟有效，超时重新获取
  • 进度保存：每10秒自动保存播放位置到 Redis
  • 倍速播放：0.75x / 1x / 1.25x / 1.5x / 2x
  • 字幕切换：中/英文字幕（VOD 支持的情况下）

3.2.4 学习进度记录

保存时机每10秒自动保存，或视频暂停/关闭时
存储Redis（热数据）+ MySQL（持久化）
续播用户打开视频，自动跳转到上次播放位置
完成判断播放到 95% 进度，标记为「已完成」

3.4 运营端功能

3.4.1 用户管理

  • 用户列表：支持手机号/昵称搜索，支持禁用（禁用后无法登录）
  • 用户详情：注册时间/最后登录/设备码兑换记录/订单记录
  • 导出：支持 Excel 导出全量用户

3.4.2 设备码管理（Phase 1 核心）

Phase 1 阶段：仅支持手动单个添加 + Excel 批量导入，不提供自动生成功能。
  • 手动单个添加：输入设备码 → 选择类型(US/IC/MX) → 选择关联课程 → 设置有效期 → 确认
  • Excel 批量导入：下载模板 → 按格式填写（设备码/类型/有效期/课程ID）→ 上传 → 系统校验 → 确认导入
  • 设备码状态：未发放 / 已发放 / 已兑换 / 已过期
  • 查询：支持按设备码/批次号/状态/类型查询
  • 导出：支持 Excel 导出，支持筛选条件导出

六、设备码管理详细设计

6.1 设备码生命周期

设备码状态流转
运营手动添加 / Excel导入
→状态：未发放
→发放给经销商/客户
→状态：已发放
→用户兑换
→状态：已兑换（锁定）
或超过有效期
→状态：已过期

6.2 手动单个添加

  • 运营人员 → 设备码管理 → 添加 → 填写表单 → 确认
  • 字段：设备码（手动输入）/ 类型（US/IC/MX）/ 有效期 / 备注
  • 设备码由运营人员自行确保格式正确、唯一，系统不自动生成

6.3 Excel 批量导入

导入模板格式（CSV/Excel）： 
设备码,类型,有效期(YYYY-MM-DD),备注
XK-US-20260327-0001,US,2027-03-27,第一批超声设备
XK-US-20260327-0002,US,2027-03-27,第一批超声设备
XK-IC-20260327-0001,IC,2027-03-27,第一批智能笼
XK-MX-20260327-0001,MX,2027-03-27,混合套餐
  • 支持下载模板 → 填写 → 上传
  • 系统自动校验：格式唯一性 / 类型有效性 / 日期格式
  • 冲突处理：设备码已存在 → 提示「设备码重复，跳过」
  • 导入完成后显示：成功数量 / 失败数量 / 失败原因

6.4 权限类型与课程关联

设备码类型解锁课程范围说明
US所有 category='ultrasound' 的课程超声类课程
IC所有 category='device' 的课程设备操作类
MX全部课程混合全解锁
