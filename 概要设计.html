一、项目概述

一句话定位

基于设备码实现软硬件闭环的垂直领域在线教育平台，为小动物（犬/猫/兔/鼠等）科研人员、兽医、工程师提供专业培训课程与直播服务。

1.1 背景与目标

小动物医疗/兽医在线教育赛道存在"供给分散、质量参差、缺乏权威认证"的问题。本平台通过以下差异化策略建立竞争壁垒：

🔐 设备码权限壁垒（核心）

购买设备附赠课程，形成硬件+软件闭环，竞品无法复制

🗄️ 医学影像数据库

建立小动物超声/CT/MRI 数据库，形成独特内容壁垒

🎥 直播培训场景

实时操作演示+互动答疑，区别于录播课同质化

✅ 合规资质先行

提前布局医疗教育资质，建立长期合规竞争力

1.2 用户画像

用户类型典型特征核心需求付费意愿
临床兽医3-10年经验、宠物医院主刀技术提升、证书、疑难病例中高
兽医技师1-3年经验、影像/检验操作设备操作、标准化流程中
设备工程师医疗设备厂商技术支持临床知识、反馈产品问题企业付费

2.3 核心设计原则

  • 前后端分离：Next.js 前端通过 RESTful API 与后端通信
  • 数据库分离：用户库、课程库、日志库分库分表（Phase3后评估）
  • 视频与静态分离：视频走 VOD+CDN，静态资源走 COS+Cloudflare
  • 设备码独立：设备码体系与用户体系解耦，通过关联表实现多对多绑定

4.3 设备码权限体系

类型对应设备课程范围绑定规则
US兽用超声仪全部超声类一台设备可绑定多类型码，权限叠加；每年限换绑2次
IC智能动物笼/监测系统设备操作+监测数据
MX综合设备套餐全部课程

4.4 视频防盗策略

分三层防护：
① URL动态签名（有效时间5分钟，防止直接下载链接）
② 跑马灯水印（显示用户手机号后4位，溯源泄露用户）
③ Referer防盗链（仅允许本域名播放）

六、接口设计

6.1 API 规范

  • 协议：HTTPS RESTful
  • 认证：JWT Bearer Token（有效期7天，Refresh Token 30天）
  • 版本：URL路径版本化，如 /api/v1/
  • 错误码：统一 {code, message, data} 结构

6.2 核心接口

模块接口方法说明
用户/api/v1/auth/send-codePOST发送验证码
用户/api/v1/auth/loginPOST登录（手机+验证码）
设备码/api/v1/device/redeemPOST设备码兑换课程
设备码/api/v1/device/my-codesGET我的设备码
课程/api/v1/coursesGET课程列表（分页/筛选）
课程/api/v1/courses/:idGET课程详情（含权限校验）
课程/api/v1/courses/:id/playGET获取播放凭证（防盗链签名）
会员/api/v1/membership/buyPOST购买会员（统一下单）
支付/api/v1/payment/callbackPOST支付回调（微信/支付宝）
进度/api/v1/progress/:courseIdPUT更新学习进度
运营/api/v1/admin/codes/generatePOST批量生成设备码

七、安全设计

🔒 传输安全

全站 HTTPS · TLS 1.3 · HSTS 强制跳转 · 证书 Let's Encrypt 自动续期

🎫 接口安全

JWT 签名验证 · 接口限流（Redis）· CSRF Token · SQL 注入防护

📹 内容安全

视频防盗链（URL签名+Referer）· 跑马灯水印（溯源）· 录屏可识别

⚠️ 合规安全

直播延迟播放30秒+人工巡检 · AI 内容审核 · 个人信息脱敏
