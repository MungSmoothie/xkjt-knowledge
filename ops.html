二、技术架构

🖥️ 前端

Next.js → CDN + Vercel 部署。多节点 CDN 加速，全国访问延迟<100ms。

⚙️ 后端

NestJS/Go → 容器化部署。Koa/Express 单机 2000 并发，4核8G可支撑10000并发。

🗄️ 数据库

MySQL → 主从架构，支持读写分离。Redis → 热门课程/用户 Session。

📦 存储

COS → 静态资源（图片/课件/视频切片）。配合 CDN 加速分发。

三、监控体系

监控类型工具告警阈值
基础设施云监控 Cloud MonitorCPU>70%、内存>80%、流量异常
业务数据自定义DAU、课程观看量、付费转化率
日志CLS 日志服务关键词告警：错误/异常/超时
告警通知企微/短信30分钟内响应

四、视频防盗策略

视频防盗是持续投入，不是一次性工作。初级：URL 动态签名（防止直接下载）。中级：Video.js 播放器 + 跑马灯水印（显示用户手机号后4位）。高级：DRM 加密（成本高，适合高价值内容）。
